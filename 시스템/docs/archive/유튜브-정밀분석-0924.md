## 5. 읽어 낸 것
1. **검색이 주 엔진이 됐다(26% → 49%, 7일 53%).** 피드는 43.7%로 내려왔다. 검색 유입은 조회율이 높아서(평균 66.5%, '아시안게임 야구' 82%) 채널 전체 '계속 시청함'도 58.4 → 60.3 → 62.1% 로 올랐다. → 제목 앞 검색어 규칙이 제대로 일하고 있다(가설 C **맞음**으로 판정).
2. **구독은 절대량으로는 처음 궤도에 올랐다.** 7일 +62(하루 8.9명) — 1,000명 마감(2027-01-31, 남은 129일)에 필요한 하루 7.1명을 넘었다. 하지만 전환율은 0.04%로 그대로라 **조회수가 떨어지면 구독도 같이 떨어진다.** 드래프트 주간 같은 이벤트가 없으면 하루 1~2명대로 돌아간다(9/16~20 수준).
3. **같은 대회 안에서도 '한국이 얽힌 반응·결과'와 '남의 경기 미리보기'는 완전히 다른 장르다.**
   - 대만 반응 90.5% · 홍콩-대만 미리보기(한국 1승 걸림) 82% · 중국-필리핀 결과 86% · 대만-태국 결과 79%
   - 필리핀-일본 미리보기 56% · 중국-팔레스타인 미리보기 51% · 일본 결과 59%
   → 한국과 연결 고리가 한 줄로 안 설명되는 경기 미리보기는 끝까지 안 본다. 남의 경기는 **결과 + 한국에 미치는 영향**으로만 다루고 미리보기는 뺀다.
4. **클릭률은 '사람 얼굴 + 이름'이 이긴다.** 상위: SSG 신인 10.6%, 하현승 일본 반응 10.0%, 삼성 신인 9.7%, 하현승 8.3%. 하위: 완봉승 1.7%, 태국전 미리보기 2.4%, 곽빈 2.5%, 최지만 2.5%, 키움 분석 2.6%, 대만-태국 결과 2.9%, 홍콩전 결과 3.9%. 국기·스코어·로고 중심 썸네일과 글자가 많은 썸네일이 하위에 몰려 있다. 노출이 43만으로 늘어서 **클릭률 1%p 가 월 4,000회**다.
5. **시청자는 긴 '일본반응' 영상을 본다.** 내 시청자가 보는 채널 1~5위: 야구 인싸이드(1.7만) · 어느이야기 · 이슈를 보다(2.3만) · 한중 인사이드 · 최강볼펜(4.8만). 이 사람들이 지난 7일 본 영상: '[일본반응] 하현승…' 101.6만회(이슈를 보다), '하현승 완벽투에 일본 야구인들 놀란 이유' 43.6만회(어느이야기). → **우리 쇼츠 시청자는 롱폼 '해외 반응' 영상의 시청자이기도 하다.** 롱폼 시청 시간(4,000시간)이 필요한 우리에게 가장 확실한 롱폼 주제는 '일본·대만 반응'이다.
6. **다시 오는 사람이 없다.** 일반 시청자 1.8 → 1.0%, 고정 <0.1%. 월간 시청자는 5.2만인데 99%가 처음 온 사람이다. 구단별 드래프트처럼 '연재'가 끝나면 돌아올 이유가 없다.
7. **나이 든 남성 채널, 여성이 조금 늘었다.** 35~64세 69.8%, 45~54세 31.4% 1위. 여성 11% → 14.6%(드래프트·박종혁 같은 인물 편 영향으로 보임, 확인 필요).
8. **좋아요 비율이 떨어진다(0.61 → 0.50%).** 검색으로 답만 보고 나가는 시청자가 늘어난 것과 같은 현상.
9. **쇼츠 시청 시간은 수익화 4,000시간에 안 들어간다.** 28일 1,096시간은 전부 쇼츠라 0시간이다. 수익화는 구독 1,000명 + (롱폼 4,000시간 또는 쇼츠 90일 1,000만 회) 중 하나인데, 쇼츠 경로는 지금 페이스(월 19만)로 불가능 → **롱폼이 유일한 길**이라는 9/18 결론 유지.
