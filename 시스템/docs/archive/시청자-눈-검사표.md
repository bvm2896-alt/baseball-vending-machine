# 시청자 눈 검사표 (영상 시각 자료) — 10/25 새벽 사용자 지적 후 공부해서 만든 기준

**왜**: 10/25 사용자 "시청자가 보기 편하게 깔끔하게 정리를 해야지" / "시각화 자료는 텍스트로만 떼우지 말고 모션그래픽·인포그래픽·애니메이션을 적절히 쓰고 충분히 읽을 시간을 주면서" / "말하는 부분에 정확한 자료가 안 나오고" / "제목이랑 내용이 가까워서 뭐가 제목인지도 모르겠어" / "크리에이터 입장에서 고민하면서 만들어, 모르겠으면 자료를 찾아 공부해" / "내가 말하지 않은 부분까지 신경 써".

**공부한 자료**
- Mayer 멀티미디어 학습 원리(2020): 일관성(필요 없는 것 빼기)·신호(강조)·중복(말을 화면에 그대로 쓰지 않기)·공간 근접(라벨은 대상 옆)·시간 근접(말과 그림을 동시에)·분절(나눠서)·사전 학습(용어 먼저)
- Bayer & Morini «Data videos 101»: 한 화면에 한두 개, 차트는 다 그려서 보여 주지 말고 쌓아서, 색·크기·움직임으로 시선 이끌기, 글은 최소, 화면 글 = 나레이션
- UC Davis 영상 화면 글 기준: 화면 글은 두 번 읽을 수 있는 시간만큼, 작은 화면 기준으로 크게
- IJNet «데이터 애니메이션 10가지»: 숫자를 다 넣지 말 것, 아이콘·그림으로 숫자 뒤 이야기, 늘 무언가 움직이되 동시에 많이 움직이지 않기

## 장면마다 O/X (만든 뒤 '다 그려진 순간' 사진과 말하는 순간 사진으로 직접 본다)

|---|---|---|
| V1 | 한 화면에 이야기 하나 — 지난 내용을 흐리게 남겨 두지 않는다. 주제가 바뀌면 새 화면 | — |
