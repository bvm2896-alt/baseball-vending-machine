## ③ 등급 계산표(공시 전 — 전부 '예상')

규정: **최근 3년 평균 연봉+옵션** 순위. 기존 FA 계약 선수와 비FA 다년계약 선수(마지막 해 제외)는 순위 산정에서 뺀다. A = 구단 3위 이내 **그리고** 전체 30위 이내 / B = 구단 4~10위·전체 31~60위 / C = 구단 11위 이하·전체 61위 이하 / 35세 이상 신규 = C / 2번째 FA = B 보상 / 3번째 이상 = C 보상.
**한계**: 3년 평균 연봉의 전체 순위표(30·60위선)를 구하지 못했다. 따라서 '연봉 순위형' 등급은 근거 강도를 따로 적었다. 구단 순위와 전체 순위가 서로 다른 칸에 걸칠 때 어떻게 처리하는지도 원문에서 확인하지 못했다.
