- [stated] 2:14 "파일 또 따로 만들지 말고 롱폼검수 누르면 생성되게 해줘. 수정본을 생성하는거잖아" — 롱폼검수는 누를 때마다 새로 만들고(건너뜀 X), 수정본은 처음 만든 날짜 폴더의 같은 파일을 덮어쓴다(새 날짜 폴더 X).
- [stated] 2:17~2:24 "KBO 공식 로고로 해줘" / "일본 구단도 NPB로 바꿔야지" — 리그 로고는 공식 로고(KBO 워드마크·NPB 로고). 리그 타이틀 엠블럼(신한 SOL)·빨간 원 대체 금지.
- [stated] 4:14 "이미지 나오는 속도는 빠르게, 너무 느릿느릿" — 나오는 시점은 그대로, 등장 움직임은 짧게. 장면 판은 말 전에, 항목·숫자는 말할 때(판단은 Claude).
- [stated] 4:22 "알약으로 하지 말고 다른걸로 대체해줘" — 묶음 이름표 등은 알약 대신 글씨+색 막대.
