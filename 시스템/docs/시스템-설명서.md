## 6. 음성

- **작업 전에 항상 묻는다: "크롬(타입캐스트 웹)으로 할지, API 로 할지"**(9/30). 둘 다 사용자 개인 타입캐스트 계정, 로그인·키 입력은 사용자. API 키는 `설정.txt` 에 사용자가 직접(Claude 는 열지 않음). 회사 PC 는 설정.txt 암호화 → `API키등록.cmd` 환경변수; 키 없으면 크롬 zip 또는 집 PC API.
- 목소리 **장운 / 스마트 이모션 OFF / 1.2x**(API). 크레딧 = 타입캐스트 합성 비용(롱폼 한 편 3,500자 한도, 쇼츠 800자, 줄당 ≈41자). 9/30 회사 PC API 403 UNUSUAL_ACTIVITY_DETECTED 있었음(우회 금지).
- **API**: 콘티 `ttsApi true` → 사용자가 지금실행/롱폼검수 누르면 PC 가 합성. 재합성 범위(바뀐 줄만/전부)·글자 수를 먼저 보여 주고 승인. 대사·속도가 바뀐 줄만 새로, 같은 줄은 재사용. `fresh.flag`(그보다 먼저 만든 줄만 재합성).
- **크롬 zip**: Claude 가 Chrome 으로 타입캐스트 웹 → 새 프로젝트(ASCII 이름) → 캐릭터 '장운' → `[contenteditable]` 에 paste 이벤트(줄바꿈마다 블록, type 한글 금지) → 새로고침 뒤 원문과 문자 해시 대조 → 다운로드 패널 "문장 별로 나누기"+전체·고음질·mp3 → `%` 폴링 → zip 을 `<시리즈>\음성\<콘티이름>.zip` 에 커밋(절대 `시스템\` 안에 넣지 않음), 콘티 `ttsApi false`·`speed 1.2`. zip 파일 수 = 구독 멘트 뺀 줄 수. 한 줄만 다시: 문장 선택 체크박스 `2+i`. 여러 편 고친 줄은 한 프로젝트에 모아 `merge_v2.py` 로 되끼움. 탭이 hidden 이면 패널 안 열림.

## 7. 두 PC 옮기기

1. PC 바꾸기 전 그 PC 에서 `깃저장.cmd`(10/16부터 음성은 voice_pack zip 으로 같이) → 다른 PC 에 도착하면 **`깃가져오기.cmd` 부터**(원격 우선, 로컬 변경은 먼저 커밋되어 안 날아감).
2. 깃에 안 올라가는 것: `work\`·`*.mp3`·`*.mp4`·`out/`·`voice/`·`assets/`·`Claude outputs/`·설정·토큰. 음성이 없는 PC 에서 만들면 전 줄 새로 합성(크레딧).
3. 음성을 따로 옮길 땐 사용자에게 시키지 말고 Claude 가 연결된 PC 에서 `device_stage` → 다른 PC 연결 때 `device_commit`(클라우드 사본은 세션 끝나면 사라질 수 있음). 받은 음성은 `시스템\work\voice_<콘티>\` 같은 폴더 이름으로, md5 대조. 롱폼을 건너뛰고 컷만 만들려면 `work\long_built.json` 에 롱폼 지문.
4. 한쪽 PC 에서 깃저장 안 하고 끈 경우(10/7·10/13 사례): 그 PC 작업분을 클라우드에 모아 두었다가 다른 PC 에 Claude 가 직접 넣고 거기서 깃저장 → 원래 PC 는 다음에 깃가져오기만(**먼저 깃저장 금지**, 충돌). 집에서 먼저 깃저장 금지(회사가 최신일 때).
5. 사용자가 PC 를 끄거나 옮긴다고 하면 답 첫 줄에 깃에 안 가는 것(음성·mp4)과 깃저장 여부를 확인·요청하고, 가져올 게 있으면 PC 가 켜져 있는 동안 바로 받는다.
