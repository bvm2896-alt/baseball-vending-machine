## 5. 읽어 낸 것
1. **피드가 돌아왔다 — 이벤트가 크면 검색이 피드를 부른다.** 9/24 검색 49 → 43.7%, 피드 43.7 → 49.0%(7일은 46 : 45.5). 절대치는 둘 다 늘었다(검색 9.2만 → 14.6만, 피드 8.3만 → 16.4만). 7일 표에서 **피드 유입의 평균 조회율(84.9%)이 검색(66.2%)보다 높다** — 9/22 §0의 "피드는 조회율이 낮게 찍힌다"는 이 채널 규모에선 이제 반대다. 검색으로 확인만 하고 나가는 사람보다, 피드가 골라 보여준 사람이 더 끝까지 본다. → 피드가 밀어주는 건 **초반 이탈이 적은 편**이니, 훅 3초가 검색어만큼 중요해졌다.
2. **구독은 '반응·왜·우리 팀' 편에서 나오고, '결과·발언 전달' 편에서는 안 나온다 — 가설 F 판정 자료.** 편별 구독 수를 처음 뽑았다. 높은 쪽: 순위 요약 한화 탈락 0.124%(4.8천/6), 한일전 일본 반응 0.095%(5.3천/5), 한일전 미리보기 0.072%, KIA 신인 0.063%. 낮은 쪽: 일본 감독 발언 0.008%(1.2만/1), 한일전 0-5 패배 0(8.2천), 홍콩전 결과 0(3.6천), 홍콩-대만 미리보기 0(4.5천), 드래프트 총정리 0.026%. 같은 아시안게임인데 **'일본이 우리를 어떻게 봤나'(반응)와 '우리 팀 신인 누구'는 붙고, '몇 대 몇으로 졌다'와 '감독이 뭐라 했다'는 안 붙는다.** 구독 146명 중 상위 6편(대만 반응 17·KIA 11·병역 9·총정리 8·경우의 수 7·사회인야구 6)이 58명.
3. **조회율 100%가 넘는 편이 나왔다.** 대만 반응 "한국이 도와줘야 해" 104.7% — 끝까지 보고 한 번 더 본다. 그 편이 조회·구독 둘 다 1위. 순위 요약 한화 탈락(98.9%)·홍콩전 결과(97.3%)·병역 16명 흔들(98.9%)도 있다. 공통점은 **길이 51~56초 + 결론이 마지막 한 줄에 있음**(누가 응원하나 / 탈락 확정 / 누가 흔들리나). 1:05 넘는 편은 60%대가 많다(홈런왕 1:24 57%, 완봉승 75%).
4. **클릭률은 아시안게임 편이 낮다(4.0~4.5%) — 노출은 제일 많다.** 병역특례 노출 5.9만/4.3%, 일본 감독 4.1만/4.0%, 대만 반응 3.4만/4.0%, 한일전 패배 3.0만/5.3%. 신인 편(7.5~9.9%)·하현승 편(8.1~9.9%)의 절반이다. 태극기·국기·스코어 썸네일이 검색 결과에서 다른 채널 썸네일과 구분이 안 된다. 노출 72만이라 **클릭률 1%p = 월 7,200회**. 가설 G 실험은 아직 안 했다(9/24 목록 7편 그대로).
5. **롱폼 1편은 실패다.** 3:47짜리를 평균 1:15(33%)만 봤고 클릭률 2.3%. 시청 시간 ≈55시간. 4,000시간에 1.4%. '해외 반응 롱폼' 가설 I 는 이 편이 반응 편이 아니라 분석 편이어서 판정 못 한다 — 결승 뒤 '일본·대만 반응' 롱폼으로 다시 시험.
6. **경쟁 지형이 바뀌었다.** 내 시청자가 보는 채널 1~5위가 KBO 공식(50만)·압도하라·크보오프너(13.7만)·크보딱(4.8만)·랭킹의민족(3.7만) — 9/24의 '일본반응' 채널들이 아니라 **KBO 전문 채널**이다. 이 사람들이 본 영상: 랭킹의민족 '최지만 kt행 실화냐 드래프트 총정리' 42만, 크보딱 '1라운드 총정리' 30만, 압도하라 'KIA 전체 지명 결과' 25.5만 — **우리와 같은 제목을 10~20배 조회로 가져간다.** 우리 총정리 3만은 그들 뒤에 붙는 검색 2위권이다. 같은 검색어에서 이기려면 제목이 아니라 **썸네일과 3초 훅**이다(§5-1·4와 같은 결론).
7. **여전히 아무도 다시 안 온다.** 신규 99.1%, 재생목록 유입 28일 10회, 채널 페이지 0.6%. 구독 209명은 있는데 구독자 시청 시간 0.3%. 재생목록·고정 댓글(9/22 §6-2, 9/24 §6-5)은 아직 미실행 — 3주째.
8. **다시 방문 유도 편(90일)**: 하현승 두 번 당한 일본 반응 '매우 많음', 김도영 코뼈·사회인야구·5연패 전력 비교·최지만·삼성 vs KT 경우의 수·감독 3명 '많음' — 전부 **인물 + 사건 + 의견** 편. 총정리·결과 편은 목록에 없다. §5-2와 같은 그림.
9. 자막 3.7%, 좋아요 0.53%, 한국 96.1%(해외 유입이 줄어 검색 채널 성격이 더 짙어짐), 35~64세 69%, 여성 14.7% 유지.

## 6. 할 것 (우선순위)
1. **결승(9/27 오늘) → 귀국(9/28) → 병역 혜택 확정을 '반응·왜' 편으로 잇는다.** 총정리 1편(검색용) + **일본 반응 1편 + "왜 이겼나/졌나" 1편**. §5-2 대로 구독은 뒤 두 편에서 나온다. 결승 편 제목은 이미 '아시안게임 야구 결승'(검색어 1위 계열)으로 나갔다.
2. **썸네일 A/B — 아시안게임 편 4개(병역특례·일본 감독·대만 반응·한일전 패배) 먼저.** 노출이 3~6만인데 4%대라 손실이 제일 크다. 국기·스코어 대신 **선수 얼굴 + 이름 + 한 줄**. 제목·설명 그대로 두고 10/4 재측정(가설 G 판정).
3. **훅 3초를 편마다 검수 항목으로.** 피드 조회율 84.9%가 검색을 넘었다 → 피드가 밀어주는 조건은 초반 이탈이다. 콘티 검수 때 "첫 문장에 결론 방향이 있나"를 본다.
4. **길이 50~60초, 결론은 마지막 줄.** 100% 넘은 편들의 공통 구조. 1:05 넘는 편은 줄인다.
5. **재생목록 + 고정 댓글 — 이번 주 안에.** 아시안게임 편 20개를 '2026 아시안게임 야구' 재생목록으로, 신인 10편을 '2027 신인 드래프트 구단별'로. 3주째 미실행이고 재생목록 유입이 10회다.
6. **롱폼 2편은 '결승 일본·대만 반응' 6~8분.** 분석 롱폼(33%)은 접고 반응으로 가설 I 를 제대로 시험한다.
7. 자막 .srt 업로드(3.7%).

## 7. 가설 판정
- **C**(제목 앞 고유명사/검색어 → 검색): 맞음 유지. 검색 절대치 9.2만 → 14.6만.
- **E**(구단별 시리즈 → 채널 페이지): **기각(현재 구조로는).** 채널 페이지 0.6% 제자리, 재생목록 10회. 재생목록·고정 댓글을 안 걸었으니 "시리즈만으로는 안 온다"까지만 확정.
- **F**(총정리는 구독 0, "왜/반응"이 구독): **맞음.** 편별 구독 전환 — 반응·왜·순위 탈락 0.05~0.12% vs 결과·발언·총정리 0~0.026%. 단, 총정리도 절대량으로는 8~9명씩 줬으므로 "총정리는 검색용, 반응 편은 구독용" 세트로 간다.
- **G**(썸네일 클릭률): 미실행 → §6-2.
- **H**(한국과 연결 안 되는 미리보기 50%대): 맞음 재확인(태국 67%, 필리핀-일본 58%, 중국-팔레스타인 59% vs 한국 관련 82~98%).
- **I**(해외 반응 롱폼): 판정 보류 — 1편은 분석 롱폼(33%)이라 반증 자료가 아님.
- **신규 J**: 이벤트 주간엔 피드 유입의 조회율이 검색보다 높다(84.9 vs 66.2) → 훅 3초가 피드 노출을 정한다. 다음 이벤트(포스트시즌)에서 재확인.
- **신규 K**: 50~60초 + 마지막 줄 결론 편은 조회율 95%+ → 길이 규칙으로 확정할지 10편 더 보고 판정.
