# Claude Code 에서 돌릴 것 (집 PC, `야구자판기\시스템` 폴더에서 `claude` 실행)

아래 프롬프트를 그대로 붙여 넣으면 됩니다. 결과 파일은 전부 `시스템\` 아래에 생기므로 Cowork(콘티 담당)가 바로 읽을 수 있습니다.

## 1. 매일 밤 — 유튜브에서 콘티 재료 뽑기 (Agent Reach)

```
CLAUDE.md 의 "콘티 보강 재료" 규칙대로 해줘.
YouTube에서 오늘 KBO 경기 하이라이트(KBO·TVING 공식)와 감독 경기 후 인터뷰 영상을 찾아 자막을 받고,
1위 싸움(삼성·KT)과 3위 싸움(LG·KIA)에 관한 발언, 부상·복귀·아시안게임 관련 발언만 뽑아
data\extra_2026-09-12.md 에 저장해줘. 항목마다 영상 제목·주소·시각·발언자·원문 인용을 적고,
숫자와 이름은 koreabaseball.com 이나 기사로 확인되면 "확인됨"이라고 표시해.
```

(날짜는 그날 콘티 날짜로 바꾸세요. 밤에 만들면 다음 날 날짜.)

## 2. 주 1회 — 잘 되는 야구 쇼츠 분석해서 템플릿 개선 (/watch 첫째)

```
YouTube에서 "KBO 순위" "야구 순위 분석" 쇼츠 중 조회수 높은 영상 3개를 골라서
각각 /watch <주소> --detail balanced --resolution 1024 로 본 다음,
notes\reference-2026-09-13.md 에 표로 정리해줘:
훅 첫 문장(그대로), 첫 3초에 화면에 뜬 것, 자막 위치·크기·줄 수, 장면당 평균 길이(초),
숫자를 보여주는 방식(표/그래프/큰 숫자), 마지막 질문 문구, 썸네일 문구.
마지막에 우리 template.html·thumb.html 과 비교해서 바꿀 점 5개를 "왜"와 함께 써줘.
```

이 파일이 생기면 Cowork 에 "notes\reference-….md 읽고 템플릿에 반영해줘"라고 하면 됩니다.

## 3. 한 번 — 튜토리얼 영상을 스킬로 만들기 (/watch 셋째)

첫 대상은 "쇼츠 첫 3초 훅 만드는 법" 같은 영상 하나만.

```
1) PowerShell:  python C:\Users\sh705\tutorials\gemini_review.py "<영상주소>" --out notes\gemini-pass.md
2) claude 안에서:  /watch <영상주소> --detail balanced → 결과를 notes\watch-pass.md 로 저장
3) "notes\gemini-pass.md 와 notes\watch-pass.md 를 비교해서 확인됨 / 한쪽만 / 충돌로 나눈 SPEC.md 만들어줘.
    시간·개수는 버리고 규칙·문장 패턴·예시는 그대로 보존."
4) "SPEC.md 기준으로 skill-creator 로 shorts-hook 스킬 만들어줘."
5) "shorts-hook 스킬의 핵심 규칙을 시스템\CLAUDE.md 의 '콘티 규칙' 아래에 5줄로 요약해 넣어줘."
```

5번이 있어야 Cowork(콘티 담당)도 같은 규칙으로 씁니다. 스킬 자체는 Claude Code 안에서만 살아 있습니다.
