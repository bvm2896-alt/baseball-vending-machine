# 피드 회복 2주 계획 — 2026-10-01 ~ 10-15 (분석 채팅 확정, 제작 채팅 적용)

> **(10/2 개정) 사용자 결정: 롱폼 1편을 쪼개 쇼츠를 만든다, 단독 쇼츠는 거의 없다.** 아래 계획 1번(매일 단독 쇼츠 1~2편)은 **'롱폼 1 + 컷 쇼츠' 세트로 바뀌었다.** 조회율 90%+ 구조(훅 3초·결론 마지막 줄·1:20 이하)·같은 검색어 하루 한 편·결과 전달 금지는 컷 쇼츠에 그대로 적용한다. 절차는 `야구자판기-제작전-프로세스.md` §4~§7.

## 왜 이 계획인가 (10/1 진단)
- 9월 중순엔 올리면 몇백 회가 바로 찍혔는데 10/1 편들은 몇 시간째 100 미만(10/1 실사: 구자욱 부상 41회 · 힐리어드 27회 · 가을야구 5팀 24회, 9/30 편들은 1.2~2.0천). 원인은 채널 쪽 세 가지: ①쇼츠 피드 유입이 28일 22.6% → 최근 48h 5.3%로 꺼짐 ②최근 편 조회율 58~64%(9월 상위 95~105%) + 9/30 김도영 3편 몰아 올리기 ③아시안게임 검색어 소멸. 구자욱 부상 편은 뉴스 인기만 있고 유튜브 신호가 없는 '결과 전달' 편(가설 R).

## 10/1 채널 실사에서 확인한 것 (사용자 정정 반영)
- 구독자 607, 영상 90편, 재생목록 5개 이미 있음("6주째 미실행"은 분석 채팅 오류).
- 롱폼②(66만): 고정 댓글 있음(사용자 확인)·하트 있음. 비어 있는 것: 설명란 상단 구독 유도·링크, 재생목록 지정('선택'), 종료 화면(확인 필요), 상위 댓글 답글.

## 계획
1. **(10/2 개정) 세트로 간다.** 롱폼 1편 + 그 롱폼을 자른 컷 쇼츠. 다음 롱폼: 10/13 「정규시즌 성적표」(10/12 종료 D+1). 단독 쇼츠는 예외(순위 요약 등, 사용자 판단).
2. **소재는 유튜브 신호가 있는 것만.** 정찰 온도를 '유튜브 신호'와 '뉴스 신호'로 나눠 적고, 유튜브 신호 0이면 롱폼 주제에서 뒤로.
3. **롱폼은 이벤트 D-1/D+1.** 게시 전에 설명란 첫 2줄·재생목록 지정·종료 화면을 완성하고, 게시 직후 고정 댓글(법칙 11).
4. **롱폼②·③·① 설명란 첫 2줄·재생목록 지정·종료 화면·댓글 답글** — 고정 댓글은 이미 있다. 문안: "매일 프로야구 순위·이슈 1분 요약 채널입니다. 구독 → 재생목록 링크 / 롱폼③ 링크".
5. **판정.** 세트마다 분석 채팅이 롱폼 + 컷 쇼츠 각 편 + 롱폼 유입의 'Shorts'·'채널 페이지' 칸을 본다(가설 U). 가설 R·S·T 판정도 같이.
6. **포스트시즌 달력.** 10/12 정규시즌 종료 → 10/13 롱폼 세트, 대진 확정 → '포스트시즌 5팀 확률' 롱폼 세트, 한국시리즈 → 시리즈 전날 '승리 확률' 롱폼 세트. 10월 FA 명단·11월 골든글러브도 세트로.
