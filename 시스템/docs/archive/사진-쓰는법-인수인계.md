## 2. 이번 채팅(10/21 골든글러브 컷 쇼츠)에서 실제로 한 순서
1. **목록부터 본다** — `device_list_dir` 로 `선수이미지\카드`, `선수이미지\누끼` 를 열어 선수 이름으로 고른다(예: 디아즈 → `FA9_디아즈_경기`, `G18_디아즈_B`, `G18P_디아즈`). 파일 크기·이름만으로 후보를 좁힌다.
2. **눈으로 봐야 할 몇 장만 클라우드로 올린다** — `device_stage_files` 로 후보 3~10장만(전체 폴더 X). 올라온 파일은 `/mnt/user-data/uploads/야구자판기/선수이미지/…` 에 생긴다. 여러 장을 한 판(연락판)으로 붙여 Read 로 보고 정면·해상도·사진 종류를 고른다.
3. **콘티에 이름만 적는다** — 장면 `"img": "카드/…"`, 질문 화면 `"faces": ["카드/G18P_…"]`, 썸네일 `"thumb": {"img": "누끼/…", "cutout": true, …}`. 사진 파일 자체는 PC 에 그대로 있으므로 콘티(json)만 PC 에 넣으면(`device_commit_files`) 끝.
4. **미리보기는 클라우드에서** — 올려 둔 사진으로 `tools/preview.py`(장면)·build.make_thumb(썸네일)을 돌려 본다(아래 4장). PC 렌더와 같은 템플릿이라 결과가 같다.
5. **은행에 없을 때만 새로 만든다** — 아래 3장.

### 인터넷에서 받기가 안 되는 이유 (우회 금지)
- 클라우드에서 뉴스 사이트(osen.co.kr, sports.khan.co.kr 등)로 가는 연결은 프록시가 막는다(403 CONNECT tunnel failed). 다른 방법으로 우회하지 않는다.
- GitHub 은 열려 있어 누끼 모델은 받을 수 있다: `curl -sSL -o ~/.u2net/isnet-general-use.onnx https://github.com/danielgatis/rembg/releases/download/v0.0.0/isnet-general-use.onnx` (178MB, 깃에 올리지 않음). huggingface·pip 색인은 막혀 있음(onnxruntime·opencv·PIL 은 이미 설치돼 있음).
- 그러니 "사진 다운로드"가 필요해 보이면 먼저 은행 목록을 다시 보고, 그래도 없으면 사용자에게 요청한다.

## 4. 클라우드에서 PC 와 같게 미리보기 하는 법
PC 폴더를 올려 둔 `/mnt/user-data/uploads/야구자판기/` 는 읽기 전용이라, 작업 폴더에 **링크로 된 거울**을 만든다.
```bash
G=<스크래치패드>/gg; U=/mnt/user-data/uploads/야구자판기
mkdir -p $G/야구자판기 && cd $G/야구자판기 && mkdir 시스템
for x in $U/시스템/*; do b=$(basename $x); case $b in episodes|tools|work) cp -r $x 시스템/;; *) ln -s $x 시스템/$b;; esac; done
ln -s $U/폰트 폰트; mkdir -p 선수이미지
for d in $U/선수이미지/*; do b=$(basename $d); mkdir 선수이미지/$b; ln -s $d/* 선수이미지/$b/; done   # 폴더마다 실제 폴더 + 파일 링크(새 파일을 써 넣을 수 있게)
mkdir -p 시스템/data && cp <rank_latest.json> 시스템/data/   # build.py 가 찾음
```
- 나중에 stage 한 사진은 `ln -s` 로 거울에 하나씩 더 건다.
- 장면 미리보기: `PV_SEC=4 python3 -X utf8 tools/preview.py episodes/X.json template_long_v.html out.html` → playwright 로 줄 끝 프레임 캡처(크롬 `/opt/pw-browsers/chromium`, `NODE_PATH=$(npm root -g)`).
- 썸네일: build.load_episode → `EP['thumb']=…` → `build.make_thumb(EP, out.jpg)` (thumb_issue.html + thumb.js, `CHROME_PATH=/opt/pw-browsers/chromium`).
- 로고 파일(`KBO_logos`)은 올리지 않으면 미리보기에서만 빠진다(PC 에선 나옴).
