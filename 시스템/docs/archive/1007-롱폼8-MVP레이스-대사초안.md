## 5. 변수·모순 체크 (v1 단계)
- '네 명이 1위를 하나씩' → 오스틴은 OPS·장타율·루타, 곽빈은 ERA·탈삼진으로 여러 개라 **모순** → 「서로 다른 부문 1위」로 고침.
- WAR → 사이트마다 1위가 다름(위 §1) → **넣지 않음**. 시청자 댓글로 WAR를 물으면 「계산하는 곳마다 달라 공식 기록만 썼다」고 답.

- 김도영 '아홉 경기'는 코뼈·AG 외 결장이 섞였을 수 있음 → '등'.
- 곽빈 남은 등판(두산 2경기) — 미확인이라 변수로 쓰지 않음.
- 투표가 정규시즌 직후라 KIA·LG 가을야구 성적은 무관 — 6줄과 43줄이 부딪히지 않게 43줄은 '정규시즌 3위 싸움'으로.
