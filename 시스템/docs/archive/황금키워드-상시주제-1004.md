# 황금 키워드(궁금한데 영상이 없는 주제) — 2026-10-04 밤

사용자 요청: "일본 사회인 야구처럼 사람들이 궁금할 만한데 영상이 올라와 있지 않은 주제(황금 키워드)를 뽑아 달라. 「일본은 왜 아시안게임에 회사원을 보낼까」는 사람이 궁금하지만 영상이 많지 않아 내 영상에 트래픽이 몰렸다."

## 0. 롱폼②가 터진 구조(채널지표 법칙 3·4·가설 O) — 황금 키워드의 조건
- **전국이 같은 장면을 봤다**(결승 0-5, 회사원 투수가 한국을 막음) → 그날 모두가 같은 질문을 가짐 → **한국어로 그 질문에 답하는 영상이 없음** → 탐색(홈 피드)이 밀어 48h 51.8만.
- 반대 사례 롱폼③(한국 실업야구 역사): 영상은 없었지만 **질문 자체가 전국에 없던 소재** → 48h 1,696. 즉 '영상 없음'만으로는 안 되고 **'그 주에 전국이 가진 질문'이어야** 한다.
- 그래서 아래 후보는 전부 **붙일 사건(날짜)**을 같이 적었다. 상시 주제라도 사건 D+1에 올린다.

## 1. 검증 방법(10/4, 크롬 미연결 → 클라우드에서 할 수 있는 것만)
- 공급: 구글 `site:youtube.com` 검색으로 한국어 '해설' 영상이 있는지(뉴스 클립·순위 쇼츠는 해설 아님).
- 수요: 유튜브 자동완성(suggestqueries) + 스튜디오 검색어(히구치 신 1.2%·일본 사회인야구 0.6%) + 기사·커뮤니티 글 유무.
- **못 한 것**: 유튜브 검색 결과의 조회수·업로드일(robots 차단), 네이버 자동완성·지식인(차단). 크롬이 연결되면 후보마다 유튜브 조회수순 상위 10개 조회수와 스튜디오 '내 시청자가 본 콘텐츠'로 재검증한다.
