# 롱폼⑩ FA 돈값 — 10/10 검수판 수정 기록

## 사용자 지적 → 수정
- 순위(4위) 아래로 계약(4년 100억): 순위 그림은 그대로 두고, 기록은 그 아래에 붙인다.
- 같은 그림은 그대로 두고 글만 새로 뜬다. 한화 카드(38→39), 막대 묶음(64→66), 사람 카드(145→146), 김범수 칸(113→114), 강백호 칸(36→37) 모두 위치 고정·다시 뜨지 않게 했다.
- 최형우 '40세 8개월' 글자가 막대에 묻히던 문제: 글자를 한 줄로 막대 위에 두고, 화살표는 막대 높이로 옮겼다.
- "단순하게 들어간다고": 15줄을 쉼표 없이 이어 읽게 했다(+ 표시).
- 텀: 롱폼⑨ 기준으로 gapScale 1.05, pauseMax 0.4 (무음 26.4% → ⑨ 23.0% 목표).
- 숫자: 스물두 명, 스물한 명, 스무 명, 마흔여덟 명.
- "돈값한 선수 N위는"(5~1위), "돈값한 선수 순위부터".

## 영상 전체 확인에서 추가로 고친 것
- 홍건희·김재환 이름이 44px로 작게 나오던 버그: 글 칸 폭 계산을 고쳤다.
- 강백호·이영하 묶음이 화면 통째로 작아지던 문제: 기록을 그래프 옆 배지로 옮겼다.
- 강백호 사진이 화면 왼쪽 밖으로 잘리던 문제: 가운데 맞춤에 제한을 걸었다.
- 조상우 홀드 카드가 겹쳐 화면이 0.81배로 줄던 문제: 기록 칸 하나로 합쳤다.
- 이승현 순위가 사라졌다 다시 나오던 문제: 순위를 계속 유지하게 했다.
- 장성우 빈칸: 앞 장면 기록을 유지했다.
- 김범수 카드 설명이 24px로 작던 문제: 문구를 빼고 김재환 카드를 흐리게 했다.
- 시작할 때 빈 화면이던 장면(16·64·99·138·140): 첫 칸이 바로 뜨게 했다.
- VS 동그라미만 떠 있던 장면: 왼쪽 카드와 같이 뜨게 했다.
- 돈 아이콘 ¥ → ₩.
