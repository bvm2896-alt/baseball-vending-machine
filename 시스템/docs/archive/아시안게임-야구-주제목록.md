**사용자 결정(9/22)**: 아시안게임은 **모든 경기를 다 다룬다.** 지난 경기 = **리뷰 + 각국 반응(+ 다음 날 "왜")**, 예정 경기 = **전력분석 + 각국 반응 + 예상**. 하루 배치는 **아시안게임 2 + 순위 1**.
