## 4. 나레이션 규칙 — ★ 9/20 새벽에 바뀐 것
- **속도는 타입캐스트에서 낸다. build.py 의 atempo 배속은 쓰지 않는다(콘티 `"speed": 1.0`, `pace` 도 안 씀).** ffmpeg atempo 로 1.22배(첫 줄 pace fast 까지 1.32배) 늘린 음성이 **"기계음 섞인 듯 거북하다"**는 지적. atempo 는 1.1 넘어가면 금속성 왜곡이 들린다. 타입캐스트 속도 1.2x 는 모델이 그 속도로 말하는 거라 깨끗하다. **쇼츠 `SPEED=1.18` 도 같은 문제일 수 있다 → 다음 쇼츠부터 타입캐스트 1.2x + SPEED 1.0 으로 바꿔 보고 비교**
- 타입캐스트 웹 프로젝트 `6aad5597a1155159c919f267` (54블록 = 콘티와 1:1): **장운 / 스마트 이모션 OFF / 감정 일반 / 속도 1.2x / 고음질·mp3·문장 별로 나누기**. 첫 블록은 쉼표 없이(한 호흡). 원음 54줄 209초
  - 속도는 전체 선택(블록 클릭 → ctrl+a) 뒤 속도 칸의 숫자 입력에 1.2 → Enter. 각 블록 오른쪽에 1.2x 뱃지가 붙는지 확인
  - 스마트 이모션 ON 은 서현 때 시도했다가 장운에선 OFF 로 되돌림(유지율 77~84% 나온 하현승 쇼츠 설정)
- `lines` 는 **`{narr, sub}`**. `narr` 숫자 전부 한글, ` / ` 호흡. `sub` 는 `|` 로 같은 개수. `build.py narr_check` 통과
- **타입캐스트 편집 주의(9/19 사고)**: 블록 안에 `type` 으로 글자를 치면 **첫 글자 뒤 커서가 0번 블록 맨 앞으로 튀어** 다른 블록들이 망가진다. 실행취소도 일부만 된다. **`execCommand('insertText')` 는 화면만 바뀌고 저장이 안 된다.** 되는 방법: 블록을 Range 로 선택 → **`ClipboardEvent('paste')` 를 DataTransfer 로 합성해 dispatch** → 4초 뒤 새로고침해서 확인. 블록 삭제는 내용 지운 뒤 빈 블록을 클릭하고 BackSpace. 유니코드 이스케이프로 한글을 넣을 땐 글자 하나씩 확인(쳐/쳤 같은 오타가 났다)
- 한 줄만 다시 받기: 블록 선택 → 다운로드 → 선택 구간 → 문장별 → 문장 선택(체크박스는 하나씩 0.5초 간격으로 클릭해야 반영) → 줄당 ~40
- 음성 폴더를 직접 조립할 때: `work\voice_<편>\NN.mp3/.txt/.segs.json` 을 tts.py 의 split_zip(앞뒤 무음 -38dB 자르기, 192k) + mark_breaths(호흡 자리 0.10초, 첫 줄은 안 넣음)와 똑같이 만들고, **`full.src` = zip 절대경로|mtime 정수|b0.10**. `device_commit_files` 는 mtime 을 새로 찍으니 zip 을 넣은 뒤 PC mtime 을 다시 읽어 도장 찍기. 호흡 자리를 잘못 잡으면(마지막 음절 앞 쉼) segs.json 을 손으로 `[0, 경계]`·breaths 0 으로
- 이번엔 zip 을 통째로 바꿨으니 `롱폼만들기.cmd` 가 tts 부터 다시 자른다(54파일 = 54줄)
