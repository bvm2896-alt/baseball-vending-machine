## 3. 해볼 가치가 있는 방향 (우선순위)

### 1순위 — 시리즈 비중을 바꾼다
현재 순위 3 : 이슈 2 : 분석 1 구조를 **이슈/인물 3 : 분석 2 : 순위 1**로.
- 순위는 **하루 1편, "오늘의 KBO 순위" 하나로 통합.** 1위·3위·5위 싸움을 따로 3편 내지 말 것 — 그게 75회·31회를 만든 원인.
- 대신 늘리는 건 **"인물 + 사건 + 반응"**. 검증된 유일한 검색 엔진이다.

### 2순위 — "반응" 시리즈를 정식 코너로
`하현승 일본반응`이 6,383회, 유지율 77.3%, 검색의 절반. 이건 우연이 아니라 포맷이다.
- `OO 일본 반응` / `OO 미국 반응` / `외국인 선수 OO 현지 반응` / `해외 매체가 쓴 OO`
- 경쟁이 약하고, 검색어가 명확하고, 감정이 붙어서 끝까지 본다.
- 드래프트(9/21)·아시안게임(9/19~27)·포스트시즌·MLB 진출 협상에 계속 붙일 수 있다.

### 3순위 — 훅 3초 재설계 (이탈 47.6% → 35% 목표)
- 현재: 상황 설명형("작년 2위 한화가 1년 만에…") → 유지율 66%
- 잘된 것: **사람 이름 + 감정**("일본 4번 타자가 '실력이 턱없이 부족했다'") → 77%

`야구 모르는 사람도 아는 규칙` / `역대 기록` / `FA·이적시장` / `해외파 근황`.

## 4. 구독자 늘리는 법 (0.06% → 0.3% 목표)

쇼츠에서 구독은 "같은 채널을 두 번 이상 만났을 때" 생긴다. 지금 고정 시청자가 0이라는 건 **두 번째 만남이 없다**는 뜻.

1. **엔딩을 바꾼다.** 지금은 질문으로 끝난다(좋음). 여기에 **다음 편 예고 한 줄**을 붙인다.
   - "내일 아침엔 드래프트 1순위가 얼마를 받는지 계산해볼게요" — 구독할 이유를 만든다.
2. **"매일 아침"을 말로 박는다.** 나레이션 마지막에 "야구자판기, 매일 아침 7시" 고정. 시청자의 71%가 35~64세 — 이 층은 루틴에 반응한다.
3. **관련 동영상 링크를 반드시 건다.** 지금 채널 페이지 유입 0.8%, 재생목록 0%. 쇼츠 편집 화면에서 같은 구단·같은 인물 편을 서로 연결하면 1회 시청이 2회가 된다.
4. **고정 댓글.** 마지막 양자택일 질문을 그대로 고정 댓글로. 댓글 총 44개(조회 대비 0.16%)는 너무 적다. 댓글은 추천 신호이자 재방문 신호.
5. **커뮤니티 탭 주 2회.** 순위표 이미지 + 투표("이번 주 5위는?"). 게시물이 아직 0개다.
6. **시리즈 넘버링.** "순위 요약 #12"처럼 번호를 붙이면 연재물로 인식된다.
7. **댓글 전수 답글.** 하루 10개도 안 되는 지금이 답글 100% 달 수 있는 유일한 시기.
