## 1. 화면은 글자만 나오는 장면 금지 — 전부 인포그래픽·모션 (9/26 사용자 확정, 모든 영상)

- 발단: `big`("대만이 5점 차 미만 승 → 일본·한국 결승") 같은 **글자 한 덩어리 장면**, 국기 두 개 + 글자(`matchup`)로 경우의 수를 '설명한 척'한 것 → "이해시키려는 마음이 없어 보인다, 텍스트로 대체하지 말고 그림으로, 움직이는 모션그래픽으로".
- **원칙**: 나레이션이 말하는 내용을 화면이 **그림으로 보여 준다**. 순위·성적이면 표, 조건·경우의 수면 눈금/갈림길, 공식이면 공식 카드, 비교면 막대. 글자는 제목·라벨·짧은 결론 한 줄까지만.
- `big` 은 원칙적으로 쓰지 않는다(쓰면 사진·로고·숫자 배지·표 등 그림 요소와 함께). 콘티 쓸 때 장면마다 "이 장면에 그림이 뭐가 있나"를 확인하고, 글자뿐이면 바꾼다.

  - `formula` — 분수 공식 카드 `{title, left:[위,아래], right:[위,아래], op, note}`.

- 다시 만들 때는 `work/voice_<편>/fresh.flag` — 이보다 먼저 만든 줄만 다시 합성.
- **한 편 통째 합성(`ttsWhole`)은 폐기**: 줄 경계를 무음으로 자르는 게 부정확해 자막·장면이 엉망("개판이다"). 줄마다 합성으로 간다.

## 14. 9/27 롱폼 2차 검수 지적 (모든 영상 적용)
- **화면에 "제 생각" 글자 금지.** 나레이션이 "제 생각엔 ~예요"여도 화면 제목엔 넣지 않는다(예: "사회인 일본은 약체가 아니다").
- **"댓글로 남겨 주세요" 같은 문구 화면에 금지.** 롱폼 엔딩 카드(`endcard.html`) 위 문구는 콘티 `endTop` 을 줄 때만.
- **한눈에 뜻이 보여야 한다.** 제목 + 아이콘 + 숫자만 던져 놓지 않는다("24명 중 미필 / 사람 그림 / 16명" 은 무슨 말인지 모름). 무리를 나눌 땐 `groups`(예: 미필 16명 = 금메달이면 병역 혜택 / 병역 해결 8명) 처럼 **각 무리에 이름·뜻**을 붙인다.
- **야구공 아이콘 반복 금지**(4안타 = 공 4개, 10점 = 공 10개, 32팀 = 공 32개 → "창의력 없다"). 숫자는 `tiles`(큰 카드), 선수 기록은 `profile` 칩(사진+이닝·투구 수·피안타·실점), 토너먼트는 `bars` 로 32→16→8→4→2→1.
- 롱폼 `bars` 는 가로 화면용으로 새로 짰다(가운데, 폭 1500, 숫자 104px). 6줄이면 자동으로 촘촘하게.
- **줄이 하나씩 늘어나는 표(h2h)는 앞 줄을 다시 그리지 않고 새 줄만 아래에 붙는다.** 앞 줄 내용·크기(k)·폭은 장면마다 같게(생성기에서 한 목록을 잘라 쓴다). 표 폭은 기본 1000px — 이름과 점수 사이가 멀면 안 된다.
- 롱폼 사진 옆 글씨는 크게(빈 공간을 채운다), profile 칩은 4개 이하로(5개면 작아진다).
- 미리보기: `PV_SEC=4 python3 tools/preview.py …` 로 줄당 4초를 주고 **장면 끝 모습**을 확인한다(기본 1초면 애니메이션이 덜 끝난 모습이 찍힌다).

## 16. 9/28 롱폼 제작 원칙 (사용자 지시)
- "롱폼 영상에는 이미지나 설명을 위한 시각화 자료가 생명. 정말 모르는 사람이 봐도 이해되게. 쓸데없는 미사여구는 빼고 깔끔하게. 인포그래픽·모션그래픽이 많고 자연스럽게."
- 콘티 표는 줄마다 **화면(모션)** 칸에 무엇이 어떻게 움직이는지 적는다. 글자만 장면 0개.
- 개념은 그림 설명(예: 실업야구 = 회사 → 사원증 → 월급 → 야구장), 숫자는 카운트·꺾은선·막대·흐름도, 역사는 연표·팀 수명 막대(gantt).
- **미사여구 금지는 화면(시각화 자료) 안의 글자에만.** 화면엔 이름·숫자·짧은 라벨("1964 · 13팀", "운영비 3배+")만. **나레이션·자막은 말맛 있게 그대로**("무려, 앞다퉈, 황금기" 같은 표현 OK) — 9/28 사용자 정정.
- **롱폼 목차**: 훅(첫 2~3줄) 뒤에 "이 영상에서 볼 건 N가지예요 / …"로 목차를 말로 부르고 칸이 차례로 켜진다. 챕터 첫 줄마다 같은 목차가 나오고 해당 칸만 강조(9/28 사용자 제안).

## 17. 인물 사진은 그 시절 사진으로 (9/28 사용자 지시, 모든 영상)

## 18. 9/28 롱폼③ 1차 영상 검수 → 고친 것 (모든 영상 적용)
- **자막·음성 싱크(원인·해결)**: 타입캐스트는 쉼표 자리에서 안 쉬거나 쉼표 아닌 곳('셋째,' '경찰야구단이 ..')에서 쉰다. 옛 tts.py 는 "쉼 개수 = 경계 수면 순서대로" 붙여 경계가 한 칸씩 밀렸고(자막이 1~2초 먼저/늦게), 그 자리에 0.1초 호흡 쉼을 끼워 **단어 가운데서 말이 끊겼다**(2줄 "선수였|고", 41줄 "경찰야구단이|이천십구"). → `tts.seg_bounds` 를 **쉼을 뺀 '말하는 시간' 기준 + 구간별 말 속도가 고르게 되는 배정(동적 계획법)** 으로 교체. 쉼 없는 경계엔 호흡 쉼을 끼우지 않는다. `qa_voice` 도 같은 방식, 사람이 고정한 경계(`"lock": true`)는 안 건드림.
- 이미 만든 음성은 크레딧 없이 클라우드에서 고침: 잘못 끼운 쉼(디지털 무음)을 빼고 경계를 다시 잡아 쉼을 다시 끼움(51줄). 파형으로 확인 못 한 경계는 사람이 `OVERRIDE` 로 고정.
- **이어지는 그림은 사라졌다 나타나지 않는다**: 같은 그림에 줄만 늘면 `cont: True`(기존 줄 그대로, 새 줄만 아래). 막대 표는 뒤에 나올 줄 자리를 미리 비워 두고, 배지는 빈자리 위에 띄운다(표가 들썩이지 않게). 이름표도 앞 장면 것을 유지하고 새 이름만 추가.
- **목차**: 목차를 읽을 때 **읽는 칸을 그 호흡 시작에 맞춰 강조색**(build.py 가 `EP.segT` = 줄별 호흡 시작 시각을 넘김). 챕터 시작 목차는 사라지지 않고 앞 강조가 풀리며 이번 칸이 서서히 강조(글씨 크기 대신 색·살짝 확대 — 칸이 들썩이지 않게).
- **가운데 정렬**: 그림 덩어리(이름 칸 + 막대)가 화면 가운데. 이름 칸 폭은 전체 이름 길이에 맞추고 왼쪽 정렬. 깔때기 옆 칩은 막대 옆에 띄워 막대는 위 단과 같은 가운데 줄. 인용 카드 따옴표는 모서리에 띄워 글씨가 카드 가운데.
- **나레이션에 나온 숫자·연도는 화면에도**(6줄 1946 시작). 자료에 인원이 없으면 숫자 대신 글씨('시작').
- **질문 문장은 물음표를 tts 에만**(`보세요?` → 끝을 올려 읽음). 화면 자막엔 물음표 안 씀. 줄 안 한 박자 쉼이 필요하면 그 경계에 쉼 추가(2줄 "57년 동안이요" 뒤 0.4초).
- 부제(신청자 수 등)는 라벨의 0.7배·진한 색으로 잘 보이게. 막대 라벨은 `\n` 줄바꿈 가능("야구\n2018 계획").
