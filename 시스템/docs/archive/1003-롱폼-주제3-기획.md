# 롱폼 주제 3개 기획 (2026-10-03, 분석 채팅)

사용자 결정(10/3): 롱폼은 두 종류(이벤트·상시) 합쳐 매일 1편 목표, 안 되는 날은 이틀에 1편. 최종 목표 = 시청 시간·조회수 극대화. 이 문서는 롱폼⑥(10/4~5) 다음 편 3개. **대사·팩트체크는 사용자가 고른 뒤에 한다.**

## 기획 1 · 이벤트형 — 「2026 KBO MVP, 누가 받아야 해? | 김도영·구자욱·힐리어드·오스틴·곽빈 5명 직접 비교」
- **올릴 때: 10/6~7 아침** (정규시즌 마지막 주, 홈런왕 공동 1위 김도영·힐리어드 41개 — 결론이 안 난 지금이 '누가 받아야 해?' 질문의 온도가 가장 높다). 10/12 종료 뒤엔 컷 쇼츠로 '최종 결과' 한 편.
- **왜 이 주제:** 골든글러브 예측 영상이 2주 만에 49.9만 → 시상 예측 수요가 크다. MVP는 4주째 새 영상이 없다. 인물 5명 = 컷 쇼츠 5편(인물 편 구독 상위, 법칙 5).
- **챕터 (8~10분):** 오프닝(5명 얼굴 + "올해 MVP는 누구?") → MVP는 어떻게 뽑나(기자 투표, 지난해 결과) → 김도영(홈런 41·OPS·부상 공백·아시안게임) → 구자욱(타율 1위·햄스트링 부상) → 힐리어드(홈런 41·타점·KT 1위 공헌) → 오스틴(타율·홈런·LG) → 곽빈(평균자책점 1위·아시안게임 결승) → 투표에서 갈리는 기준(팀 성적·경기 수·임팩트) → 제 예상 1~5위 + 질문 "여러분은 누구 찍을래요?".
- **썸네일:** 5명 경기 사진(가운데 김도영·구자욱) + "MVP 누구?" 큰 글씨.
- **필요한 자료:** KBO 기록실(10/5 기준 최종 직전 기록, 게시 전날 갱신) — 타율·홈런·타점·OPS·WAR 대체로 공식 지표만, 평균자책점·이닝·탈삼진 / 지난해 MVP 투표 결과와 기준(기사) / 선수별 본인 코멘트(MVP·홈런왕에 대해 한 말) — **이름 나오는 선수 전원 코멘트(10/3 규칙)**.
- **컷 쇼츠 후보:** 김도영 vs 힐리어드 홈런왕(10/12 결정 뒤) · 구자욱 타율 .371인데 MVP는? · 곽빈 투수 MVP 가능할까.
- **주의:** '스탯티즈 WAR'은 못 읽음(차단) → 공식 기록만. 판정 문장("받아야 한다")은 의견임을 밝힌다.

## 기획 2 · 상시형 — 「다음 메이저리거 누구야? | 김도영·곽빈·원태인… 언제 갈 수 있는지 날짜 직접 계산」
- **올릴 때: 10/8~9** (또는 기획 1과 순서 바꿔도 됨 — 시즌 결과에 안 묶임).
- **왜 이 주제:** 사이버 윤석민 '차기 메이저리거' 9일 만에 69.3만, MLB Korea 김도영 13.6만 → 수요 큼. 경쟁 영상은 "실력이 되나"인데 우리는 **"규정상 언제 갈 수 있나"** — 꿀반장식 '직접 계산'(우리 채널 강점: 팩트·날짜).
- **이미 확인한 재료(롱폼⑥ 조사):** 곽빈 "최고의 상태로 미국에 가는 게 목표"(9/28) + 아시안게임 등록일수 보상으로 **2027 시즌 뒤 포스팅 가능**(스포츠동아 9/29) / 원태인 이번 겨울 **FA 자격으로 해외 도전 가능**(마이데일리 9/29), "인정해 준다면 도전할 생각은 언제든"(2025.12) / 김도영 아시안게임 금메달로 병역 해결, "빠르면 2028 시즌 뒤 포스팅"(파이낸셜뉴스 9/28) / 노시환 계약에 포스팅 조항(마이데일리 9/29) / 김주원(NC)도 2027 뒤 가능(스포츠동아 9/29 제목).
- **챕터 (8~10분):** 포스팅 vs 해외 FA, 등록일수가 뭔지(그림) → 원태인(이번 겨울, FA) → 곽빈·김주원(2027 뒤) → 김도영(2028 뒤) → 노시환(계약 조항) → 안현민 등 다음 후보 → 지난해·올해 KBO→MLB 사례(송성문 등) → 질문 "누가 제일 먼저 성공할까?".
- **썸네일:** 김도영·곽빈·원태인 얼굴 + "언제 가?" 
- **필요한 자료:** KBO 규약(포스팅 7시즌·해외 FA 기준 — 원문 확인 필수), 선수별 등록일수 기사, 본인 코멘트 전원, MLB 스카우트 관심 기사.
- **주의:** 규약 숫자(7시즌·9시즌 등)는 KBO 규약 원문 또는 기사 2곳으로만. '간다' 단정 금지.

## 기획 3 · 상시형 — 「2027 FA 시장, 돈 쓸 수 있는 팀은 어디야? | 10개 구단 샐러리캡 지갑 직접 계산」
- **올릴 때: 10/10~11** (정규시즌 종료 직전, FA 이야기가 시작되는 시점. 정승베 '2027 샐러리캡 직접 계산'이 하루 1.9만 → 지금 뜨는 검색).
- **왜 이 주제:** 롱폼⑤⑥에서 이미 나온 질문의 답 — "삼성은 상한까지 5억, 구자욱·원태인 둘 다 못 잡는다", "키움은 하한선 때문에 돈을 써야 한다", "롯데 170억 계약 끝". 10개 구단을 한 표로 정리하면 상시 검색('kbo 연봉 순위'·'샐러리캡 하한선') + FA 시즌(11월) 둘 다 받는다.
- **챕터 (8~10분):** 샐러리캡·경쟁균형세·하한선이 뭔지(그림) → 2025 구단별 연봉 총액 표(KBO 발표)와 2026·2027 상한액 → 지갑 넉넉한 팀 / 빠듯한 팀 / 써야 하는 팀(키움) → 팀별 FA 대상자와 연결(삼성 구자욱·원태인, LG 홍창기·박동원, 두산 양의지 등) → 결론 "이번 겨울 큰손은 ○○" + 질문.
- **썸네일:** 돈다발 그림 ✕(추상 금지) → 구단 대표 FA 얼굴 4명 + "돈 있어?"
- **필요한 자료:** KBO 2025 구단별 상위 40명 연봉 합계 발표(2025.12) 원문, 2026~2028 상한액(시사저널 8/15: 2026 143억9723만·2027 151억1709만·2028 158억7294만 — 원문 재확인), 하한선 60억6538만·미달 시 30% 기금, 경쟁균형세 초과 사례(LG 2024 12억1489만), 2026 연봉 총액 보도가 있으면 갱신.
- **주의:** 2026 구단별 실제 총액은 아직 공식 발표 전일 수 있음 → '2025 공식 + 2026 보도'로 구분해서 말한다. 계산은 "제 계산"으로 밝힌다.
