# 대사 무오류 검사표 (10/26 사용자 지시 — 모든 대사에 적용)

사용자: "내용은 오류, 변수, 모순이 전혀 없어야 하고 대사도 실수가 없어야 돼. 특히 숫자 읽기, 텀이 들어가야 할 문장에 안 들어가 있는 거, 텀이 들어가지 말아야 할 문장에 들어가 있는 거 정확하게 확인하고."

대사를 쓴 쪽(분석 채팅)이 먼저 아래 A~D를 줄마다 확인하고, 독립 검수 에이전트 2명(yagu-rule-audit)이 다시 대조한다. X가 하나라도 있으면 고치고 새 에이전트로 다시 검수 → **X 0일 때만 '준비 완료'**. 서브에이전트는 Projects 도구가 없으니 대사·이 검사표·근거모음을 로컬 파일로 넣는다.

## A. 오류 (사실)
- 숫자·이름·이닝·점수·투수 기록은 하나도 빠짐없이 KBO 박스스코어 또는 기사 **본문**과 대조한다(제목만 본 것 금지).
- '잘 던짐'과 '승리투수', '세이브'와 '홀드'를 구분한다.
- 반올림 금지 — 기록 그대로 쓴다. 확률은 KBO 공식 자료만.
- 한쪽 근거만 고르지 않는다(상대 전적은 승·패 모두 본다).

## B. 변수
- **날짜 말은 상대어 금지**: '어제·오늘·내일'은 업로드 시각이 자정을 넘으면 틀린다 → "이십오 일", "이십칠 일, 대구"처럼 날짜로.
- 2차전 선발은 공식 발표 전이면 '유력', 발표 뒤면 확정 이름.
- 연장·무승부·부상 교체·선발 조기 강판이 있었으면 해당 줄이 그 사실과 맞는지.

## C. 모순
- 줄끼리(앞에서 한 말과 뒤에서 한 말), 대사와 근거모음, '제 예상'과 마지막 질문이 서로 부딪히지 않는지.
- 대사의 숫자·명사 = 화면 항목 1:1.

## D. 숫자 읽기 (대사는 전부 한글 숫자)
| 종류 | 읽기 | 예 |
|---|---|---|
| 점수·점·실점·득점·타점·안타 수·홈런 수 | 한자어 | 오 대 사, 삼 점 차, 사 타점, 이백이 안타, 사십오 개 |
| 승·패·위·이닝·회·년·월·일·세이브·연승·매직넘버 | 한자어 | 칠 승 삼 패, 칠 이닝, 구 회 말, 삼십오 세이브 |
| 경기 수·명·살·시·번·게임 차 | 고유어 | 열네 경기, 스물두 명, 두 시, 세 번, 두 게임 차 |
| 타율 | 할·푼·리 | 삼할 칠푼 일리 |
| 평균자책·OPS | 점 | 일 점 일칠, 일 점 영삼구 |
| 이닝 분수 | 과 N분의 N | 칠과 삼분의 이 이닝 |
| 영어 팀명·약어 | 한글 | 케이티, 엘지, 에스에스지, 케이비오 |
| 점수 순서 | 화면과 같게 | 화면 `삼성 3-5 기아` → "삼 대 오" |

## E. 텀 (쉼)
**텀이 꼭 있어야 하는 곳** (쉼표 또는 마침표)
- 문장 끝. 줄 가운데 '-요·-죠'로 끝나는 문장은 쉼표가 아니라 마침표.
- 날짜·장소·상대 나열: "이십칠 일, 대구, 삼성전" / 이름 나열: "김도영, 나성범, 카스트로".
- 주제어 강조(-은/-는) 뒤, '제 생각엔·하지만·그래서 제 예상은' 앞뒤.
- 훅 문장 사이(훅은 텀을 두고, 줄 뒤 텀은 짧게).

**텀이 들어가면 안 되는 곳** (한 호흡으로 이어 읽기)
- 관형어 + 명사: "가장 많은 / 백이 경기" ✗
- 소유격 + 명사: "박해민의 / 사 년 육십오 억" ✗
- 목적어 + 동사, 부사(에·로) + 동사, 주어 + 짧은 서술어: "단순하게 / 들어간다고" ✗
- 숫자 + 단위, 'N차전', '팀명 + 명사'(기아 마무리).

음성 합성 뒤에는 silencedetect(-38dB 0.12초)로 줄마다 실제 텀을 재서 위 두 목록과 다시 대조한다(영상 편집자 검수).
