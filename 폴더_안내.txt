야구자판기 폴더 구조 (2026-09-11)

야구자판기\
  지금실행.cmd(두 시리즈 다) 영상만다시.cmd 깃저장.cmd 일정확인.cmd 작업등록.cmd 메타갱신.cmd   <- 공용 실행 버튼
  오늘.txt (전체 실행일 때만 씀)
  시스템\      두 시리즈가 같이 쓰는 프로그램·콘티(episodes)·데이터. 건드리지 않음
  브랜드\ 폰트\ KBO_logos\   공용 (프로그램이 참조)
  야구순위\
     지금실행.cmd      <- 야구순위만 만든다 (콘티 episodes\날짜_순위.json)
     영상만다시.cmd    <- 야구순위 영상만 다시 (음성 재사용)
     오늘.txt          <- 이 시리즈 진행 상태
     업로드.txt 공개.txt 재생성.txt 메타.txt 종료.txt   <- 이 시리즈용 신호 파일 (여기에 만든다)
     영상\날짜\       <- 결과물 (드라이브가 있으면 OUTPUT_DIR\야구순위\날짜\)
     메모\
  야구이슈\
     지금실행.cmd 영상만다시.cmd 오늘.txt 신호 파일 영상\ 메모\ 재료\   (위와 같음, 콘티 episodes\날짜_이슈.json)
  Claude outputs\  Claude 앱이 자동 저장하는 곳 (지워도 됨)

규칙
- 콘티 파일은 두 시리즈 모두 시스템\episodes\ 에 두고, 이름 끝이 _순위 / _이슈 로 갈린다.
- 시리즈 폴더의 지금실행을 누르면 그 시리즈 콘티만 기다렸다가 만들고, 신호와 오늘.txt 도 그 폴더에서 주고받는다.
- 두 시리즈를 동시에 돌리지 말 것 (작업 폴더를 같이 씀). 하나 끝나면 다음.
