## 2. 렌더 검수판 (클라우드 작업 공간)
1. 끝 장면 전부 캡처 → 20장씩 검수판으로 보고: 사진 꽉 참·가운데·얼굴 가림·워터마크(자르기만)·사진 종류·줄바꿈·글 넘침.
2. **이동 검사(move.js)**: 장면 k 끝 → k+1 끝에서 같은 요소가 4px 넘게 움직였는지. 같은 사람·같은 묶음이면 고친다(R12 — 줄이 더해질 때 기존 글 크기 변화 포함).
3. **깜빡임 검사(flash.js)**: 모든 장면 전환(**마지막 장면 포함** — 장면 끝 시각 목록이 장면 수보다 1개 적으면 영상 끝 시각을 붙인다)에서 앞 장면 끝·뒤 장면 끝에 다 보이는 글·사진이 시작 0.03·0.15·0.3초에 사라지는지. `[위반]`(같은 묶음·같은 틀) 0건이어야 통과, `[참고]`(다른 틀로 바뀜)는 정상(R11).
4. **늦게 뜸·짧은 장면(late_check.py)**: R10·R13. 영상이 나오면 해당 장면을 2초 간격 프레임으로 다시 본다.
5. **사람 눈 확인**: 사진이 그대로 이어지는 전환은 검사 결과와 별개로 시작 0.02·0.15·0.35·0.6·끝 프레임을 직접 보고 확인한 뒤에만 "고쳤다"고 말한다.
6. 고친 장면은 시작·중간·끝 3장으로 다시 본다. 템플릿을 고치면 끝 장면 전부를 수정 전과 비교해 다른 장면이 바뀌지 않았는지 본다.
