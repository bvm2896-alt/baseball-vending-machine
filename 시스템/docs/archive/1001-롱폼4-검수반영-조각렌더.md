## 영상 수정
- 업로드: **10/1(목) 20:30** 추천(롱폼은 탐색 유입 88~91% → 저녁 폰 시간, 48시간 창이 주말까지). 콘티 `date` 2026-10-01(화면 날짜·#10월1일). 콘티 파일 이름은 그대로(음성 폴더 유지).
- 0번 줄: 「이건 2008년부터 한화의 순위표예요 / 한화는 왜 맨날 못할까요? / 결론부터 말할게요」 — 영상 시작하자마자 순위표 대사.
- 화면 매체·날짜 표기 전부 삭제(OSEN 2024.10.5 · 데일리굿뉴스 · 서울신문 2026.9.4 배지). **앞으로 화면에 출처 표기 금지** — 출처는 유튜브 설명란만.
- '사 오다' → **'영입'**: 「사오고」로 붙여 써도 타입캐스트가 숫자 4 억양으로 읽음. 1·2·3·25·26·43·50줄 + 목차·3장 제목 배지·저울 라벨. 앞으로 나레이션에 동사 '사다' 금지.
- 목차 "강했다, 한화는" → 타입캐스트가 이어 읽고, 음성 경계가 '했'·'다' 사이 파열음 틈(0.17초)에 잡혀 "강했 / 다한화는". → `tts.py`: 줄 가운데 서술형 '-다'(었다·했다·꿨다…) 구간 뒤는 쉼표 대신 마침표.
- 트레이드 장면(17줄): 조상우→KIA 뒤 티켓이 키움에 도착(줄 시작 +7.95초)하자마자 넘어감 → 줄 옵션 `holdAfter: 1.6`(MAX_GAP 무시, 최대 3초).
- 속도: 음성 1.1배(ttsTempo), 렌더 1.0.

## 렌더 시간 단축 (사용자: "수정할 때마다 처음부터 다시 만들어야 돼? 너무 오래 걸려" → "둘 다")
- **조각 렌더**(롱폼): 장면 = 조각 mp4. 지문(템플릿·사진·장면 JSON·앞3/뒤1 장면·자막 글자·프레임 수) + 시각 허용 오차 0.021초로 지난 조각 재사용. 줄 시작을 프레임 칸에 맞춰 뒤 장면이 밀려도 재사용. 앞 장면 3개 마지막 프레임 워밍업 → 전체 렌더와 픽셀 동일(장면 11개 대조). 진행 막대는 ffmpeg 로 따로.
  - 시뮬레이션: 줄 하나 길이 변경 → 장면 1개(약 2.5%)만, 장면 글자 변경 → 앞뒤 포함 5개(약 10%). 템플릿 수정 시 전부.
  - 실패하면 자동으로 예전 방식.
