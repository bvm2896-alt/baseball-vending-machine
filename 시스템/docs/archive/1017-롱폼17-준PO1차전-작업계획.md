# 롱폼⑰ 준PO 1차전 리뷰·분석 + 2차전 예측 — 10/17 밤 무인 제작 계획

18:30 예약 작업(이 대화로 돌아옴)은 이 문서대로 진행한다. 예약 작업 원문에 '리뷰 쇼츠'라고 적혀 있어도 **롱폼이 맞다**(사용자 정정 10/17 17시 — 예약 문구 수정은 안전장치에 막혀 이 문서로 대신함).

## 사용자 지시 (10/17 오후)
- 준PO 1차전(10/17 광주 KIA-LG) 리뷰를 **롱폼**으로(8분 이상, 중간 광고 2자리).
- 경기 내용 + **왜 이런 결과가 나왔는지 야구 전문가처럼 분석** — 승부를 가른 원인을 기록(투수 교체 시점·구종/카운트·상대 전적·타순/작전·수비·불펜 소모)과 감독·선수 경기 후 발언(날짜·출처)으로. 판단 문장 검증 규칙, 근거 없는 단정 금지.
- **2차전 예측도 같이** — 예상 선발 맞대결(발표 확인), 1차전 결과로 바뀐 것(불펜 소모·타격감·부상), 시리즈 흐름(역대 1차전 승리 팀 준PO 통과 비율 등 KBO 기록으로 확인되는 것만), 우리 예측은 '야구자판기 예측'으로.
- 합성 글자 수 많아도 계속(KBO_CHARS_OK=8000). 업로드는 사용자가 돌아와서. 사용자는 밖에 있음 — 묻지 말고 진행, 끝에 정리해서 보고.

4. 2차전 예측: 선발 맞대결, 달라질 것, 야구자판기 예측
5. 마지막 질문(댓글 유도) + 구독 멘트
