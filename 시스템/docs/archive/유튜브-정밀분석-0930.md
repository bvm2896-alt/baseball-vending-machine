## 4. 읽어 낸 것
1. **롱폼②의 탐색이 식는 중이다.** 일별 노출 152만(9/27) → 76만(9/28), 48h CTR 7.4%(첫날 12.4%), 조회율 45.9%(첫날 54%). 유튜브가 더 넓은(덜 맞는) 시청자에게 보여주면서 클릭·시청·구독 전환이 모두 내려온다. 그래도 48h 29.5만·5,007h — 아직 채널 조회의 88%.
2. **둘째 날부터 구독이 안 붙는다.** 9/27 전환 0.064% → 9/28 0.033% → 48h 0.036%. 롱폼② 48h 구독 79명(첫 48h 221명). 롱폼 구독은 **첫 24시간에 몰린다** — 다음 롱폼은 첫날 안에 구독 장치(엔딩 멘트·고정 댓글·종료 화면)가 이미 걸려 있어야 한다.
3. **롱폼③은 실패 — 가설 O 확정.** 48h 1,696회·노출 1.4만·CTR 3.7%. 같은 공식(왜 제목·검색어 접두·얼굴 썸네일·6분)인데 롱폼②의 1/170. 차이는 소재의 검색 온도(일본 0-5 = 전국 이슈 / 한국 실업야구 역사 = 니치)와 타이밍(D+2 밤). CTR 3.7%는 썸네일도 안 먹힌 것 — 최동원 흑백 사진은 이 시청자에게 얼굴이 아니다. **롱폼 소재 = 그 주 검색어 상위 + 사람들이 지금 묻는 질문.** 롱폼② 트래픽을 ③으로 흘리는 고정 댓글·종료 화면은 아직 없다(채널 페이지 0.3%).
4. **구독 최상위는 변함없이 순위 요약·인물·한국 승리 결과 편(0.15~0.17%) — 법칙 5·가설 N 확정.** 박종혁 51명(7일 쇼츠 1위, 롱폼 다음), 삼성 매직넘버 14, 결승 3-1 12, 한화 탈락 9, 병역 명단 12(0.111%), 병역 흔들 7(0.127%). 노출 2~1.4만짜리 작은 편들이다. 반대로 노출 5~12만 큰 AG 편(결승 경우의 수·미리보기·병역특례·일본 감독·한일전 패배)은 0.008~0.064%.
5. **검색어가 아시안게임 하나에 40% 쏠렸고, 대회는 끝났다.** 10월 첫 주에 '아시안게임 야구' 검색이 꺼지면 쇼츠 검색 유입(7일 20만)의 절반이 사라진다. 대체 온도는 **포스트시즌**(정규시즌 종료·대진·매직넘버) — 순위 요약이 구독 전환도 최상위라 이번 주 편성은 이미 맞다.

## 6. 가설 판정
- **M**(롱폼 공식 → 탐색): **부분 기각 → O로 흡수.** 공식만으로는 탐색이 안 민다. 소재의 검색 온도 + 이벤트 D+1 타이밍이 선행 조건.
- **N**(피드로 퍼진 순위·인물 편이 구독 최상위): **맞음 확정 → 법칙 5에 통합.** 7일 박종혁 0.170%, 삼성 매직넘버 0.164%, 결승 3-1 0.169%, 한화 탈락 0.150%, 병역 흔들 0.127%.
- **O**(롱폼 탐색 노출은 소재의 전국 검색 온도): **맞음.** 롱폼③ 48h 1,696 vs 롱폼② 166,852(같은 공식). 롱폼④로 재확인.
- **L**(분석 롱폼): 맞음 유지 — 7일 55.7만·11,566h.
- **신규 P**: 롱폼 구독은 첫 24시간에 몰린다(9/27 0.064% → 9/28 0.033%) → 구독 장치는 게시 전에 완성. 롱폼④로 판정.
- **신규 Q**: 이벤트가 끝나면 그 검색어 유입은 1주 안에 절반 이하로 꺼진다 → 10/7 검색어 표로 판정.
