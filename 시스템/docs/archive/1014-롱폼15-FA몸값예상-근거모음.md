표시 규칙
- **✔** = 서로 다른 출처 2곳 이상 확인 · **△** = 출처 1곳뿐(대사에 단정 금지, "~라는 보도" 수준) · **✕** = 미확인(쓰지 말 것)

- A: 구단 연봉 1~3위 + 리그 30위 이내 / B: 구단 4~10위 + 리그 31~60위 / C: 그 밖 + **35세 이상 신규 FA** / 2번째 FA = B 보상, 3번째 이상 = C 보상.

- **C등급**: 보상선수 없이 직전 연봉 150%
  - 출처: 스포츠조선 2024-11-02 https://v.daum.net/v/20241102113923595 · 일간스포츠 2026-05-21 https://isplus.com/article/view/isp202605210023 · 데일리안 2020-01-22 https://www.dailian.co.kr/news/view/863244/ · 쿠키뉴스 2024-11-02

- 타 구단 FA 영입 한도: 신청자 11~20명이면 팀당 2명, 21~30명이면 3명 ✔(OSEN 2025-11-05, 데일리안 11/8 "21명 → 3명까지")
