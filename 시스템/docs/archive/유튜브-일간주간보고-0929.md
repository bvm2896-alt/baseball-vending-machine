### 이번 주 읽어 낸 것
1. **탐색(홈 피드)이 채널의 1위 유입이 됐다 — 롱폼 하나 때문에.** 7일 탐색 36.9만(45.2%), 시청 시간의 66%. 지난주까지 이 채널은 '검색 + Shorts 피드' 채널이었다. 탐색은 쇼츠엔 6%뿐이고 롱폼②에 90.7%. 즉 **롱폼 = 탐색, 쇼츠 = 검색·피드**로 유입 엔진이 갈라졌다.
2. **주간 구독 +473 중 롱폼② 221(47%).** 나머지 252명은 쇼츠 50편에서. 쇼츠 상위는 박종혁 42(48h)·병역 명단 12·결승 3-1 12·삼성 매직넘버 7 — 어제 법칙 5(순위·인물 편)와 가설 N 그대로.
3. **롱폼②의 시청 시간 11,036h(48h)는 채널의 수익화 시청 시간 조건을 2.75배 채웠다.** 28일 누적 11,624h. 카드는 9/23 기준 10h로 멈춰 있다 → 10/1~3 반영 예상.
4. **롱폼③이 안 뜨는 건 소재·타이밍 문제, 만듦새 문제는 아니다.** 조회율 53.1%·CTR 6.0%는 ② 첫날(59%·12.5%)보다 낮지만 노출 1,259라 표본이 작다. ②의 탐색 트래픽을 ③으로 연결하는 게 유일한 지렛대.
5. **CTR 채널 평균 8.3%(28일 8.2%)** — 지난주 5.8%에서 올라온 건 롱폼② 얼굴 썸네일(10.3%) 비중. 쇼츠 AG 편은 여전히 2.5~4.6%(결승 3-1 2.5%, 결승 미리보기 4.3%).

## 4. 오늘 할 것 (우선순위)
1. **롱폼② 고정 댓글 + 설명란 + 종료 화면 → 롱폼③·재생목록 링크 — 오늘 안에.** 51.8만 명이 지나가는 길목에 ③을 놓는 것이 ③을 살릴 유일한 방법이자 구독 장치. 5주째 미실행인 재생목록('2026 아시안게임 야구', '2027 신인 드래프트 구단별')도 같이.
2. **롱폼③ 48시간 판정(9/30 밤).** 탐색 유입이 붙는지. 안 붙으면 제목을 '아시안게임 야구 한국은 왜 실업야구가 없나 | 일본 사회인 vs 한국' 식으로 롱폼② 검색어('일본 사회인야구')와 잇는 것 검토.
3. **롱폼④ 후보는 검색 온도가 있는 소재로** — 이번 주 검색어 상위: 히구치 신·곽빈 아시안게임·병역. 「히구치 신은 누구인가 — 드래프트 1순위 회사원」 또는 「병역 혜택 16명, 왜 논란인가」. 결승 온도가 식기 전(10/1까지).
4. 쇼츠는 순위 요약(정규시즌 막판 매직넘버·탈락)·인물 편 유지. AG 편 4개 얼굴 썸네일 교체(10/4 비교)는 그대로.
5. 10/1~3 수익 창출 카드 재확인 → 1단계 열리면 신청, 1,000명 도달 즉시 2단계 신청.
