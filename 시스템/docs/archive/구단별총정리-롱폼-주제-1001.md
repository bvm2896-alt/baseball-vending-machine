# 구단별 총정리 롱폼 — 주제 선정 (2026-10-01, 분석 채팅 → 제작 채팅)

사용자 결정(10/1): 야친남 너클볼 컨셉(10개 구단을 한 편에 다루는 롱폼, 반말 질문 제목, 얼굴 4~6명 썸네일, 구단 챕터)으로 우리 편을 만든다. 이 문서는 그 첫 주제들이다. 제작 채팅은 `야구자판기-수익화-제작지침.md`·`1001-피드회복-2주계획.md`와 같이 읽는다.

## 0. 이 틀의 규칙 (두 벤치마크에서 가져온 것 + 우리 법칙)
- **한 편에 10개 구단.** 쪼개지 않는다. 챕터는 구단 이름 10개(순위 순 또는 탈락 팀 → 가을야구 팀 순). 길이 8~12분(우리 롱폼②③ 6분보다 길어도 된다 — 구단 챕터가 이탈을 막는다).
- **제목 = 반말 질문 + 선택지 또는 숫자** (너클볼 "할래? 말래?" + 꿀반장 "확률 42% 직접 계산"). 제목 앞에는 우리 법칙 2의 검색어(정규시즌·FA·포스트시즌)를 둔다.
- **썸네일 = 현재 선수 컬러 얼굴 4~6명 + 글자 2~4자.** 국기·스코어·로고·흑백 ✕(법칙 10).
- **결론은 구단마다 한 줄, 마지막 챕터에 10줄 요약**(법칙 9). 설명란 첫 2줄에 결론 문장 + 구독 유도 + 재생목록 링크, 타임라인은 구단 이름, "KBO 기록실 기준, 이 채널이 직접 계산" 한 줄(꿀반장).
- **게시 전 완성**: 엔딩 구독 멘트·종료 화면(구독 + 이전 롱폼 + 재생목록 '구단별 분석')·고정 댓글 문안(법칙 11). 재생목록 '구단별 분석 — 왜 이렇게 됐나'에 넣는다.
- **소재는 시즌이 끝나도 유효한 질문**(너클볼) 또는 **이벤트 D-1/D+1 확률**(꿀반장). 뉴스 결과 전달 ✕.
- **중복 확인(10/1)**: 우리 채널에 구단별 롱폼은 아직 없다. 쇼츠 '구단별 신인' 7편(9/22~23)·'순위 요약' 19편·롱폼 ①②③(대만·일본 사회인·한국 실업야구)·롱폼④ 한화(10/1 20:30)와 제목 앞 검색어가 겹치지 않는다. 단, **한화 단독 롱폼④가 오늘 나가므로 '10개 구단 성적표' 편의 한화 챕터는 ④와 다른 각도(퇴진설이 아니라 2027 전력)로 쓴다.**

## 2. 추천 순서
1. **10/5~6 「탈락 5팀, 2027엔 가을야구 갈 수 있어?」(#6)** — 포스트시즌 전에 탈락 팀 팬 5개 팬덤을 받는다. 롱폼④ 한화의 다음 편이자 '구단별 분석' 재생목록 3번째. 꿀반장·너클볼이 안 한 자리.
2. **10/13 「정규시즌 성적표 | 10개 구단, 너희 팀은 몇 점이야?」(#1)** — 이벤트 D+1(법칙 4·가설 O). 같은 날 쇼츠 '정규시즌 최종 순위 총정리'와 검색어가 같으니 **쇼츠는 15:30, 롱폼은 09~12시**로 하루 안에 역할을 나눈다(쇼츠=검색, 롱폼=탐색).
3. **10/13~14 「포스트시즌 5팀, 한국시리즈 갈 확률」(#2)** — 대진 확정 직후. #1과 이틀 간격이면 #1 안에 '확률' 챕터로 합쳐도 된다(편수보다 온도).
4. 10/16 이후 #3 외인 재계약 → #5 마무리 → 11월 초 #4 FA → 비시즌 #7·#8.

## 3. 제작 채팅에 넘기는 스펙 (#6 기준 예시)
- 제목: 「프로야구 탈락 5팀, 2027엔 가을야구 갈 수 있어? | 롯데·NC·한화·SSG·키움 구단별 숙제 3개」
- 챕터: 00:00 오프닝(5팀 한 줄) → 롯데(9년 연속 탈락, 왜) → NC → 한화(2027 전력만 — 퇴진설은 롱폼④) → SSG(아빌라 잔류) → 키움(하현승·드래프트) → 클로징(5팀 2027 가능성 ○△✕ 한 줄씩).
- 썸네일: 5팀 현재 선수 컬러 얼굴 5명 + "2027엔?" (글자 4자).
- 길이 8~10분. 각 구단 챕터 끝 줄이 결론(법칙 9).
- 설명란 첫 2줄: 결론 문장 + "매일 프로야구 순위·이슈 1분 요약 채널, 구독 → 재생목록 '구단별 분석'". 타임라인 구단 이름. "KBO 기록실 기준, 이 채널이 직접 정리".
- 게시 전: 종료 화면(구독 + 롱폼④ + 재생목록) · 고정 댓글 문안 · 재생목록 지정. 게시 아침 9~10시(가설 T 결과가 20:30 우세면 저녁으로).
- 체크리스트 7(제작전-프로세스 §4) O/X를 콘티에 붙인다.
