## 5. 읽어 낸 것
1. **롱폼이 터졌고, 터진 이유는 검색이 아니라 탐색(홈 피드)이다.** 롱폼② 유입 88.6%가 탐색. 노출 48만에 클릭률 12~13%(채널 평균 5.8%의 두 배 이상), 평균 3:15 시청. 유튜브 홈이 '아시안게임 결승 다음 날, 한일전 패배 이유'라는 질문 제목 + 히구치 얼굴 썸네일을 골라서 밀었다. 롱폼①(3:47, 33%, CTR 2.3%)과의 차이: **이벤트 정점(결승 직후)에 올렸다 + 제목이 "왜" 질문 + 제목 앞 '아시안게임 야구' + 6분 길이.** 9/27 §5-5의 "롱폼 1편은 실패" 판정은 롱폼 자체가 아니라 타이밍·소재 문제였다.
2. **수익화 지형이 하루 만에 바뀌었다.** 9/27엔 '구독 1,000 + 롱폼 4,000시간' 둘 다 멀었다(55h). 롱폼② 한 편이 4,164h → 시청 시간 조건은 사실상 통과(반영 대기). 남은 건 **구독 615명**. 7일 페이스 26.1명/일이면 **약 24일(10월 22일 전후)**, 48시간 페이스(131명/일)면 5일. 마감 2027-01-31까지 125일, 필요 페이스 4.9명/일 — 평상시 1~2명/일로 떨어져도 이벤트 두 번(포스트시즌·FA)이면 된다. 1단계(구독 500 + 3,000h)는 며칠 안에 열린다.
3. **구독 전환 상위는 이제 셋이다: 순위 요약(0.15~0.18%), 인물 편(박종혁 0.14~0.18%), 롱폼(0.06%지만 절대량 100).** 순위 요약 삼성 매직넘버 12명(6,646회, 96.1%), 한화 탈락 8명(98.1%), 박종혁 15명(28일)·37명(48h). 셋 다 노출이 2~6천으로 작다 → **검색이 아니라 피드로 퍼진 편이 구독을 만든다.** 반면 검색 노출 4~11만짜리 총정리·결과 편은 0.01~0.04%. 법칙 5 재확인 + 인물 편 추가.
4. **'남의 경기' 미리보기·결과 편은 여전히 구독 0, 조회율 57~58%** (필리핀-일본, 중국-팔레스타인, 일본 결과). 법칙 1·H 유지. 반대로 한국 경기·"왜" 편은 90%+ (5연패인데 왜 찝찝할까 99.0%, 결승 3-1 90.6%, 일본 반응 92.4%).
5. **가설 K(50~60초 + 마지막 줄 결론 → 95%+)는 반례가 생겼다.** 홍콩전 결과 1:06 97.2%, 삼성 매직넘버 1:02 96.1%, 5연패 찝찝 1:06 99.0%, 결승 3-1 1:17 90.6%. 길이보다 **"결론이 마지막에 있는 구조"** 가 핵심이다. 1:05 넘어도 구조가 맞으면 90%+. 길이 하한을 '1:20 이하'로 완화.
6. **검색 43.7 → 45.0%, 7일은 검색 47.7%로 다시 1위.** 결승 검색 수요가 몰렸다. 검색 유입 조회율 67.3%는 피드 81~84%보다 여전히 낮다(법칙 8). 검색어 1위 '아시안게임 야구' 2.8만(15%)·계열 30%.
7. **클릭률은 AG 편이 여전히 4%대(도와줘야 해 3.8%, 병역특례 4.3%, 일본 감독 4.1%, 한일전 패배 4.6%, 홍콩 3.8~4.0%).** 얼굴+이름 편은 7.5~9.9%(사회인야구 9.9%, 결승 미리보기 곽빈 vs 히구치 9.6%, 삼성 신인 9.3%), 롱폼②(히구치 얼굴) 12.4%. **가설 G는 롱폼②가 사실상 증명했다** — 같은 주제, 얼굴 썸네일이면 2~3배. AG 편 4개 교체는 아직 미실행.
8. **다시 오는 장치는 여전히 없다.** 재생목록 14회, 채널 페이지 0.6%, 구독자 시청 0.4%, 신규 98.7%. 롱폼② 16.7만 중 채널 페이지 37·재생목록 29. 4주째 미실행. 구독 385명이 다음 롱폼을 보게 하려면 이번 주에 걸어야 한다.

## 6. 할 것 (우선순위 — 수익화 = 구독 615명)

## 7. 가설 판정
- **C**(제목 앞 검색어 → 검색): 맞음 유지. 검색 절대치 14.6만 → 18.8만. 롱폼②도 검색 1.1만.
- **E**(구단별 시리즈 → 채널 페이지): 기각 유지(0.6%, 재생목록 14회).
- **F**(총정리 구독 0 / 반응·왜 구독): 맞음 재확인 — 총정리 0.026%, 일본 감독 0.008%, 한일전 패배 0.009% vs 순위 요약 0.15~0.18%, 박종혁 0.14%, 반응 0.05~0.07%.
- **G**(썸네일 클릭률): **롱폼②로 사실상 맞음** — 얼굴 썸네일 12.4% vs 국기·스코어 AG 편 3.8~4.6%. 쇼츠 4편 교체 실험은 10/4.
- **H**(남의 경기 미리보기 50%대): 맞음 유지(57~58%).
- **I**(해외 반응 롱폼이 시청 시간을 가장 빨리 모은다): **기각 — 반응이 아니라 '왜' 분석 롱폼이 4,164h를 모았다.** 롱폼 시청 시간의 열쇠는 포맷이 아니라 §5-1 공식.
- **J**(이벤트 주간 피드 조회율 > 검색): 맞음 유지(84.5 vs 67.3).
- **K**(50~60초 + 마지막 줄 결론 → 95%+): **부분 수정 — 길이는 1:20까지 무관, 구조가 핵심.** 홍콩전 1:06 97%, 5연패 찝찝 1:06 99%, 결승 3-1 1:17 91%.
- **L**(사용자 결정: 분석 롱폼 재시험 「일본은 왜 회사원을 보낼까」): **맞음 — 압도적.** 조회율 54.1%(기준 33.1%), CTR 12.4%(기준 2.3%), 48h 16.7만·4,164h·구독 100. "새로운 도전도 필요하다"는 사용자 판단이 데이터 권고(반응 롱폼)를 이겼다. 7일·28일 재판정 예정이지만 이미 기준을 넘었다.
- **신규 M**: 롱폼은 **이벤트 정점 직후 + "왜" 질문 제목 + 제목 앞 이벤트 검색어 + 얼굴 썸네일 + 5~7분** 이면 탐색(홈 피드)이 민다 → 롱폼③으로 재현 시험(§6-1). 재현되면 법칙으로 승격.
- **신규 N**: 노출이 작아도(2~6천) 피드로 퍼진 순위 요약·인물 편이 구독 전환 0.15~0.2%로 최고 → "구독은 피드 편에서, 조회는 검색 편에서" — 10편 더 보고 판정.
