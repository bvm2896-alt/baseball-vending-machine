# 야구자판기 공통규칙 — 15차 추가분 (2026-09-30 새벽, 집 PC)

`공통규칙.md`(12차) → `13차-0924` → `14차-0926` → **이 문서** 순서로 읽는다. 겹치면 이 문서가 우선. 콘티를 쓰기 전에 이 문서와 14차 §1·§13·§14 를 체크리스트로 훑고, 미리보기(장면 끝 모습)를 찍어 한 장면씩 대조한 뒤에 PC 에 넣는다. **사용자가 먼저 지적하게 만들지 않는다**(9/30 "내가 다 설명했고 메모에 적으라고 했는데 왜 잔잔바리로 만드냐", "내가 지적하는 것들 다 프로젝트 메모리에 저장해놔").

## 1. 콘티 보고 방식 (9/30)
- "이게 콘티야? 대사를 보여줘야지" → 콘티를 만들었다고 할 땐 파일 목록·표가 아니라 **대사(나레이션) 전문부터** 보여 준다. 줄 번호마다 따로, 호흡(` / `)마다 줄을 바꿔서.
- 결정은 표로("뭘 만들겠다는 거야 표로 정리해서 말하라고"), 말투는 편하게 깔끔하게, 답부터.

## 2. 화면 글자 줄바꿈 (9/30 "가독성 좋게 줄바꿈 잘해" = 화면 안 텍스트)
- 카드(`cards.name`)·인용·`big` 큰 글씨는 낱말 하나씩 꺾이면 안 된다("우리만 / 프로 / 아마추어 / 이기고 / 군면제" ×). **한 줄 6~8자, 2~3줄, `\n` 직접 지정.** 카드 두 장 나란히면 더 짧게("우리만\n프로", "아시아 1등\n군 혜택\n우습다", "기대에\n못 미쳐\n죄송하다").
- **회색 서브텍스트(`sub`)도 줄바꿈** 신경 — 한 줄에 안 들어가면 줄이거나 뺀다("2001년생 이후 · 2023 입단 이후" ×).
- 미리보기에서 꺾임이 보이면 넣기 전에 고친다.

## 3. 서브텍스트는 진짜 필요한 것만 (9/30 "진짜 필요한 게 아닌 것들은 다 지워, 존나 이상해")
- 뺄 것: "세 번", "마지막 한 줄", "인터뷰", "불공정 승부", "프로 전력", "하태경 주장", "금메달 = 혜택", "이종성 교수 제안"처럼 나레이션에 이미 있거나 없어도 되는 말.
- 남길 것: 날짜, 기록 수치(24타수 6안타 · 홈런 1), 남은 경기 수처럼 **나레이션에 없는 정보**만.

## 4. 관계 수치는 두 항목 사이에 (9/30 "2게임 차가 기아 옆에 붙어 있으니까 모르는 사람은 이해하기 힘들다")
- "2게임 차"를 한 팀 행 밑에 쓰지 않는다 → 두 팀 아래 문장으로 **"LG와 KIA 2게임 차"**(`league.text`). 게임 차·승차·격차 전부 같은 원칙.
- 팀이 아닌 항목(제도/선발 기준, 2018/2026)을 `league` 행에 넣으면 로고 자리에 "KBO"가 떠서 어색 → `cards` 로.

## 5. 문장 (9/30)
- 못했을 땐 수식어를 붙인다: "처참했어요", "삼진으로 침묵했고", "땅볼로 허무하게 물러났어요". "달랐어요"처럼 밋밋하게 쓰지 않는다.
- 기록 얘기엔 **기록 보유자·연도**를 같이("1999년 샌더스의 40개, 27년 된 타이거즈 최다 홈런 기록").
- 뜻이 모호한 문장 금지("돌아온 첫 타석은 분명 김도영이었어요" ×) → "돌아오자마자 친 41호는 그저 그런 선수가 아니라는 증거예요".
- "밖에서도" → "해외에서도". 마지막 질문은 사용자가 준 문장 그대로("아시안게임 금메달 한 번, 병역 포인트제, 어떤 게 좋다고 생각하세요?").
- 화면 큰 글씨는 주어 포함, 그 장면만 봐도 뜻이 통하게("김도영 6경기 처참 / 복귀 41호는 증거"). 화면에 "제 생각" 글자 금지(14차 §14 재확인). 공 아이콘 반복 금지 — 매직넘버는 큰 숫자 + 뜻 한 줄.
