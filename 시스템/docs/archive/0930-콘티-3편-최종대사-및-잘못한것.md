4. 회색 서브텍스트 줄바꿈 안 봄, 필요 없는 서브텍스트("세 번", "마지막 한 줄", "인터뷰"…) 넣음.

7. 김도영편: 타율 .412 를 한 화면에 두 번(profile text + stats) — 검수 안 함. WBC 역전 투런·동점 2루타 장면에 상황 사진 없이 프로필. **상황을 말하는 장면은 전부 그 상황 사진이어야** 하는데 프로필로 때움. 막대 그래프에서 아시안게임엔 기록 서브가 있고 프리미어12엔 없음, 카드 오른쪽 공간 비어 있음. "이 삼진"(→ "삼진 두 개"), "그 홈런으로"(→ "이 홈런으로") 말 틀림. 이정후 카드에 KBO 로고(샌프란시스코여야). 제목 "WBC · 3월" 성의 없음. 마지막 질문 "김도영, 메이저리그에 갈 수 있을까요 / KBO에 계속 남을까요?" 억양 이상.
